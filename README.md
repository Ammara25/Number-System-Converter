# Number System Conveter
A clean, responsive, and real-time **Number System Converter** web application. This tool allows users to seamlessly convert numbers between **Decimal**, **Binary**, **Octal**,and **Hexadecimal** formats instantly as they type.

---

## Features
* **Real-Time Conversion:** No need to click a convert button. The App Updates all other fields instantly as you type in any input box.
* **Bi-directional:** convert from any base to all other bases fluidly.
* **Input Validation:** Automatically detects invalid characters for each specific number system(e.g., typing '2' in the binary field or 'G' in hexadecimal) and displays an "Invalid Input" warning across other fields.
* **Auto-Clear:** Clearing an input field instantly clears all other fields.
* **Responsive UI:** A modern, minimalist, and mobile-friendly design centered perfectly on the viewport.

---

## Technologies Used
* **HTML5:** Semantic structure for the converter interface.
* **CSS3:** Flexbox layouts, custom styling, and clean input formattinng.
* **JavaScript(ES6):** Vanilla JS handling real-time event listening, Regular Expression(RegEx) validation, and base-conversion logic using  built-in methods (parsInt and toString).
